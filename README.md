A GitHub-compatible git forge in a single Node process: git smart HTTP (clone and push, packfiles with delta resolution), REST v3 repositories, issues, pull requests and contents, GraphQL, and MCP tools — all over one shared in-memory store. Node stdlib only, no dependencies, no model calls.

## Run it

```sh
node --experimental-strip-types main.ts
```
